# EBay Listing Metadata PHP SDK

PHP SDK for eBay Listing Metadata APIs.

## Covered APIs

- **Taxonomy V1** — category trees, item aspects, category suggestions
- **Catalog V1 Beta** — product catalog search and lookup
- **Metadata V1** — listing policies, item conditions, return policies by category
- **Charity V1** — eBay for Charity organizations

## Specs

OpenAPI specs and GraphQL schema are in `specs/`. Implementation not yet started.
